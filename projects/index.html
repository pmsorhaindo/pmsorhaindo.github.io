How this page works

Each project's page is built from a Markdown write-up plus its GitHub Projects board, pulled into this site as data. The board table on each page is read from that project's board snapshot and filters in the browser — nothing here calls GitHub live, so numbers are as of the date shown, not the current instant. Diagrams are Mermaid flowcharts and state diagrams, rendered in your browser from the same source text written into each page. Items the source material itself marks as uncertain, unvalidated or provisional are called out the same way on these pages.
