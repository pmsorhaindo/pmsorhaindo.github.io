0. The core idea in one paragraph

A jam turns into a performable song once each section of the song is one pattern on every device, and one action moves every device to its next section together. The OXI One is the natural "conductor". Each song section becomes an arranger slot (column). A slot can send a Program Change (PC) on each sequencer's MIDI channel 2 clock ticks before the transition [OXI p.225, p.232]. One sequencer lane can point at the Octatrack's PC-receive channel, which changes OT patterns [OT §8.7.2, p.40]. The chord lane's PC changes the Hydrasynth patch [HS p.102]. Scenes and the crossfader on the OT, plus macros on the Hydrasynth, handle the movement inside a section.

1. OXI One MKII: organizing a song into sections

1.1 Structure you're working with

  • Project: holds all sequencer data. There are 20 on-board project slots, and more fit on microSD. The last autosaved project loads on power-up [OXI p.11].
  • Patterns: 16 per sequencer across 8 sequencers [OXI p.88].
  • Songs: 4 per project, built in the arranger. Songs can't be renamed. Saving a song saves the project [OXI p.221, p.225].
  • Arranger grid: rows are sequencer lanes 1–8, columns are slots (song sections). There are up to 32 slots [OXI p.224].

2. Octatrack MKII: banks, patterns, parts, scenes

2.1 Structure

  • Project → 16 banks (A–P) → each bank has 16 patterns + 4 parts [OT §10, p.52].
  • A part holds machine assignments, sample-slot assignments, FX, track parameters and 16 scenes. Each pattern is linked to one part [OT §10.2].
  • 128 Flex + 128 Static sample slots per project [OT §4.4].

Rule of thumb for performance: one song = one bank. Patterns = sections. Parts = sound sets. Patterns linked to the same part share sounds. Switch parts only when the sound set must change, because part changes also trigger MIDI-track PC sends (see §4).

2.3 Scenes + crossfader for transitions

  • Assign scene to slot A/B: [SCENE A]/[SCENE B] + [TRIG] [OT §10.3.1].
  • Lock a value into a scene: hold [SCENE A/B] + turn a DATA ENTRY knob. Remove a lock: hold the scene key + press the knob [OT §10.3.1].
  • Scene mute (bypass the scene): [FUNC] + [SCENE A/B] [OT §10.3.3].
  • Copy scene: hold scene key + [RECORD]. Paste: hold scene key + [STOP]. Clear: hold scene key + [PLAY] (do it again to undo) [OT §10.3.4–10.3.5].
  • XLV / XVOL / XDIR are scene-only volume parameters, made for crossfader fades [OT §10.3.2].

Transition recipe: keep scene A = "section as written". Make scene B = "the exit" (filter close, reverb/delay wash, XVOL down on the drum tracks). Fade to B over the last bars, change the pattern, then snap the fader back to A. The arranger can also set scene A/B per row [OT §14.1.1].

2.4 Octatrack arranger

  • Toggle arrangement mode: [FUNC] + [ARR]. Open the menu: [ARR] [OT §14, p.87].
  • 8 arrangements per project, 256 rows each. Columns: PAT, REP, OF(fset), LN, SCENE A/B, T(ranspose MIDI tracks), B(PM), M(ute) [OT §14.1.1].
  • Insert row: [FUNC] + [DOWN]. Remove row: [FUNC] + [UP]. Special PAT entries: HALT, LOOP, JUMP, REM (text cue) [OT §14.1.1].
  • Save and reload the arrangement from the ARR menu. An asterisk means unsaved [OT §14.1.3–14.1.7].
  • It sends and receives MIDI Song Position Pointer [OT §14].

Use REM rows as on-screen cue cards ("BUILD 8 BARS", "WAIT FOR LIGHTS").

2.5 Sample-slot organization and one-shot horn hits

  • Name files before you import them. The slot list shows filenames. You can rename on the device under PROJECT → SYSTEM → CARD TOOLS → FILE MANAGER → RENAME, but be careful [OT §8.5.5]. Put the BPM in loop filenames (e.g. pad_loop_70.wav) and the OT will use it as the tempo hint [OT §13.2.4].
  • Reserve a slot range per role. For example Flex 1–16 drums, 17–32 tonal loops, 33–48 one-shots/stabs, 49–64 textures. (This is a convention, not a device feature.)
  • Dedicate tracks to one-shot material. For example T7 = horn stabs/phrases, T8 = long drones (Static machine). Long phrases should be one-shot trigs: [FUNC] + [TRIG] on an existing trig turns it yellow. Re-arm with [STOP] + [STOP] (while stopped), or [YES] in grid-record mode [OT §12.4.5, p.66].
  • To fire phrases by hand in time, set the sample's QUANTIZED TRIG (audio editor → ATTRIBUTES) to PAT.LEN or a step value [OT §13.2.4].
  • SAVE SAMPLE SETTINGS (audio editor → FILE) keeps trim/slice/attributes with the file across projects [OT §13.2.5].
  • Before export or travel: COLLECT SAMPLES copies used audio into the project folder, and PURGE SAMPLES clears unused slots [OT §8.4.1].

2.6 Saving: parts vs projects vs banks

  • Day-to-day changes are auto-cached to the CF card and survive power-off inside a project [OT §4.12].
  • Project SAVE ([FUNC] + [PROJ]) sets the restore point, and RELOAD returns to it [OT §8.4.1]. Files: .work = live state, .strd = saved state [OT §8.5.5].
  • Part SAVE sets the restore point for [FUNC] + [CUE] live reloads [OT §10.2.2–10.2.3].
  • SAVE/RELOAD CURRENT BANK: same idea per bank [OT §8.4.1].
  • SYNC TO CARD before you pull the CF card [OT §8.4.1].
  • Recorder buffers are NOT kept after power-off. Save them in the audio editor or with [FUNC] + [REC3] [OT §9].

3. Hydrasynth Desktop: patches per section, performance bank, macros

3.1 Program change in

  • SYSTEM SETUP → MIDI page 4: MIDI RX channel (Omni or 1–16), Clock Sync (Internal / USB / MIDI In / Auto) [HS p.100].
  • MIDI page 6: Pgm Chg RX = On (and Pgm Chg TX if you want the Hydra to send PCs) [HS p.102].
  • Banks: 8 banks × 128 (A–H). To change bank, send CC#0 = 0 and CC#32 = 0–7 (A–H) plus a PC. Otherwise only the patch inside the current bank changes [HS p.102].
  • PC numbering: the manual doesn't state whether PC 0 = patch 001. (unverified: test it.) The OXI manual warns that 0- vs 1-based numbering varies by device [OXI p.232].

3.2 Build a performance bank

  1. Pick a spare bank (e.g. H) as your "live" bank.
  2. Save each section's sound into consecutive locations, e.g. H001 Intro pad, H002 A-section chords, H003 B-section chords, H004 peak. [SAVE]: Knob 1 sets the location, Knob 5 the bank, Knob 2 the name (16 characters), Knob 3 the category, Knob 8 the colour [HS p.94]. - First time: turn Protect off (SYSTEM SETUP page 1, knob 4), or saving is blocked [HS p.94].
  3. Now PC n always means section n, which keeps the OXI PC values easy to remember.
  4. Also add them to Favorites (4 groups × 8) for manual fallback: [BROWSE] → Control button 8 → assign. Recall with [SHIFT] + [BROWSE] [HS p.93].
  5. Back up the bank with ASM Manager [HS p.95].

3.3 Macros for live tweaks

  • 8 macros per patch, each with up to 8 destinations. They live on the Home page [HS p.81].
  • Edit: [MACRO ASSIGN] → Control button of a macro. Name it on page 4 (up to 8 characters) [HS p.81–82].
  • Hold [INIT] + turn a knob on Home: the macro jumps straight to 0.0 [HS p.81].
  • Macro button mode (SYSTEM SETUP page 2, knob 4): Toggle / Trigger / Switch / Reset [HS p.83].
  • On save, Knob 4 = Return / Save / Convert decides whether the current macro positions are kept. Use Save if a section patch should start with a macro already turned up [HS p.82, p.95].
  • Suggested consistent layout across all live patches (convention): M1 brightness/cutoff, M2 movement/LFO depth, M3 space (reverb/delay mix), M4 grit/drive, M5 attack/release ("swell"), M6 pitch/detune, M7–8 per-patch specials. Your hands then know where things are whatever the patch.
  • Option: CC/NRPN control from the OXI or OT. Param RX = CC or NRPN (MIDI page 6). The CC map is in the manual's MIDI CC chart [HS p.102, p.116].

4. Sync and control: who drives whom

4.1 Recommended topology A: OXI is the master and conductor (best for chord-led songs)

OXI One  ──TRS MIDI out (DIN adapter)──►  Octatrack MIDI IN
                                           Octatrack MIDI THRU ──► Hydrasynth MIDI IN
  • OXI: clock source INT ([Shift] + [Stop] while stopped) [OXI p.257]. Config → MIDI → MIDI Transport Msgs Send = On [OXI p.275].
  • Octatrack: [FUNC] + [MIDI] → turn on CLOCK RECEIVE + TRANSPORT RECEIVE, and PROG CH RECEIVE on a fixed channel (e.g. ch 10) [OT §8.7.2, p.40].
  • Hydrasynth: Clock Sync = MIDI In, Pgm Chg RX = On, MIDI RX = its own channel [HS p.100, p.102].
  • Section changes: in the OXI arranger, hold each slot pad and set PrCh (and Bank) per lane. The chord lane's PC goes to the Hydra. A spare lane set to the OT's PC channel (no notes needed; blank slots can still send PC/Bank) changes OT patterns [OXI p.232].
  • Per-pattern PC without the arranger: sequencer setup page 1 ([Shift] + Seq [n]) has Ch / Out / PC. That PC is sent when the pattern loads [OXI p.127].

4.2 Topology B: Octatrack is the master (best for sample-led or ambient sets with heavy scene work)

  • OT: CLOCK SEND + TRANSPORT SEND, PROG CH SEND on a channel. This sends a PC when the OT pattern changes [OT §8.7.2].
  • OXI: sync = MIDI. Config → MIDI → PC receive global channel = the OT's PC channel. Incoming PC n selects arranger column n (column 1 = PC 1) [OXI p.232, p.275].
  • Hydra: PC from an OT MIDI track. NOTE SETUP has BANK / PROG / SBNK, and these are sent each time a pattern linked to a different part becomes active [OT §15.4.2, p.92]. So one OT part per Hydra patch lets the part change pull the patch with it. Or let the OXI's per-pattern PC do it.
  • OT PC numbering: the OT manual doesn't publish which PC value maps to which pattern. Community convention is PC 0–127 = A01–H16. (unverified: confirm with the OXI MIDI monitor, [Shift] + [Back] [OXI p.278]).

4.3 Ableton Live 12 (optional)

  • As recorder only: let the hardware master run and set Live to follow MIDI clock. Tune Sync Delay per device in Settings → Link, Tempo & MIDI (Ableton; [OXI p.257]).
  • As conductor: MIDI clips can send Bank / Sub-bank / Program on launch (Clip View → Extended Clip Properties) (Ableton 8.3.2). One Session scene per section can then fire PCs to all three devices.
  • Don't run two masters. Exactly one device sends clock and everything else receives.

6. Workflow: turn a jam into a performable arrangement

  1. Capture first. Right after the jam, [Shift]+[Save] on the OXI and [FUNC]+[PROJ] on the OT, and save any Hydra edits to a scratch location. Record a stereo bounce if you can.
  2. Duplicate the project on the OXI ("Duplic proj here") and use SAVE TO NEW on the OT, so the arrangement work never touches the original jam [OXI p.13; OT §8.4.1].
  3. List the sections you actually played (intro, A, B, peak, breakdown, outro) and their rough bar counts. Fill in the cheat-sheet table.
  4. OXI: put each section's material into the same pattern slot number across sequencers. Use "Save patt here as copy" to branch variations, [Shift]+[Copy] to extend pages, and rename each pattern (e.g. INTRO, CHRS1).
  5. Octatrack: one bank for the song, one pattern per section in the same order. Group patterns onto as few parts as possible. Move one-shot phrases to dedicated tracks as one-shot trigs. Save every part so [FUNC]+[CUE] works.
  6. Hydrasynth: save each section's sound into the performance bank in section order, with consistent macro roles. Turn on Pgm Chg RX.
  7. Wire the control path (topology A or B), set the channel plan, and confirm with the OXI MIDI monitor ([Shift]+[Back]).
  8. Build the OXI song: [Arranger], then [Arranger] + column pad for each section. Set PrCh/Bank per slot. Set repeats (∞ for jams, counts for a fixed song). Choose launch quantization. Save the song (Knob 2).
  9. Design transitions: OT scene B per section as the exit, and Hydra macro moves written in the table.
  10. Write the new parts you need as fresh patterns in empty slots, then insert them as arranger columns.
  11. Rehearse at full length with the arranger armed. Note any rough changes, fix them, and save everything (OXI project + song, OT project + parts + arrangement, Hydra patches).
  12. Back up: OXI copy to SD (Project menu → "Copy to SD card") [OXI p.14]. OT: SYNC TO CARD and copy the CF card to a computer. Hydra: ASM Manager.

7. Pitfalls

  • OXI unsaved patterns aren't what the arranger plays. The arranger loads saved patterns [OXI p.229]. Save first.
  • OXI arranger disarms on every Stop. Re-arm with [Shift]+[Arranger] before Play [OXI p.229].
  • OXI power state: the manual says the prior state is restored and the last autosaved project loads at power-up [OXI p.10–11]. How reliable that is if the battery dies mid-edit isn't documented (unverified), so quick-save anyway. Check Inactivity Power-Off Time in Config so it doesn't sleep at a long gig [OXI p.277].
  • Octatrack: never switch off while the CARD LED blinks [OT §4.12]. Recorder buffers are lost at power-off [OT §9]. Copying a pattern doesn't copy its part [OT §12.9.1]. Part reload only works on saved parts [OT §10.2.3].
  • OT part changes: SILENCE TRACKS decides whether old samples ring on or cut when the part changes [OT §8.6.3]. MIDI-track PROG/BANK fire on part change, so an unexpected part change can also change the Hydra patch [OT §15.4.2].
  • OT pattern changes are quantized to the end of the pattern by default (CHAIN AFTER = PAT.LEN, overridable per pattern) [OT §8.6.3]. If the OXI sends a PC late in a section, the OT changes at the end of its current pattern. Keep pattern lengths aligned across devices. How the OXI's "2 ticks early" PC lines up with the OT's queue in practice is (unverified: test at your tempo).
  • Hydra edits vanish on PC. Safe Edit doesn't block incoming program changes [HS p.98]. Save before arming the song.
  • PC off-by-one between devices (0- vs 1-based) [OXI p.232]. Verify with the MIDI monitor.
  • Clock drift/jitter: use one master. Turn off clock receive on every device that shouldn't follow, so you don't get loops. Keep MIDI Thru settings sane: OXI TRS/USB Thru defaults are in Config → MIDI [OXI p.275]. With a DAW, set Sync Delay [Ableton]. The OXI falls back to its internal clock if the external clock stops, which can mask a dropped cable [OXI p.258]. The Hydra can't sync to an incoming CV clock [HS p.100].
  • Hydra Protect = On blocks saving the first time [HS p.94].

8. Pre-gig checklist

Night before

  • ☐ OXI: project + song saved ([Shift]+[Save]), copied to SD
  • ☐ OT: project SAVE, all parts SAVE ALL, arrangement saved, SYNC TO CARD, CF backed up
  • ☐ Hydra: performance bank saved and backed up (ASM Manager). Protect back On to prevent accidental overwrites
  • ☐ Cheat sheet printed (large font) + channel plan
  • ☐ Full-length run-through with the arranger armed

At the venue

  • ☐ Power, then check every device loaded the right project/bank
  • ☐ Clock master set. Slaves show external sync. Tempo correct
  • ☐ Press Play on the master: does everything start together? Stop: do all stop?
  • ☐ Step through every section once and confirm the PCs land on the OT and Hydra (MIDI monitor if not)
  • ☐ OT one-shots re-armed ([STOP]+[STOP] while stopped)
  • ☐ OXI arranger armed (blue) right before you start
  • ☐ Crossfader on the A side. Scenes per cheat sheet. Hydra macros at their start positions
  • ☐ Levels/gain staging at the mixer. Headphone cue checked
  • ☐ Spare cables: MIDI (TRS-A adapter for OXI!), USB-C, power

Unverified items (test on your rig)

  1. Hydrasynth PC numbering (does PC 0 = patch 001?).
  2. Octatrack PC value → pattern mapping (community: 0–127 = A01–H16) for both PROG CH SEND and RECEIVE.
  3. How the OXI arranger's PC (sent 2 ticks before its transition) lines up with the OT's PAT.LEN pattern-change queue.
  4. How reliable OXI autosave/restore is after an unexpected power loss.
  5. The slot-range, channel-plan and macro-layout suggestions are conventions, not device requirements.
